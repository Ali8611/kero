# KeroMega - الموقع الرسمي للستريمر وصانع المحتوى 🎮⚡

موقع Landing Page احترافي وعصري للستريمر **كيرو ميجا (KeroMega)** بنمط **Dark Gamer Aesthetic** مع مؤثرات نيون وزجاجية خفيفة، ومشغل صوتي عائم متطور (Music Player Widget) مع قائمة تشغيل (Playlist).

---

## 🌟 مميزات الموقع:
- **تصميم Dark Gamer متطور:** خلفية داكنة مع شبكة سيبرانية وإضاءات نيون بألوان Kick الخضراء المميزة والـ Cyber Cyan.
- **متجاوب 100% (Responsive):** تجربة مثالية على الهواتف والأجهزة اللوحية والشاشات الكبيرة مع قائمة هاتف منبثقة.
- **مشغل موسيقى عائم (Floating Music Player):**
  - قائمة تشغيل (Playlist) مدمجة وسهلة التعديل من خلال ملف `js/player.js`.
  - أزرار تشغيل، إيقاف مؤقت، المسار التالي، والمسار السابق.
  - شريط سحب وتقديم تفاعلي (Seek Bar) يحسب الوقت الفعلي والدقائق.
  - موجات صوتية متحركة (Equalizer Animation) وقرص يدور عند التشغيل.
  - تحكم سلس بمستوى الصوت وخيار الكتم السريع (Mute).
  - إمكانية تصغير المشغل وإظهار قائمة الأغاني بالكامل.
- **أقسام متكاملة:**
  - هيرو ترحيبي مع شارة البث المباشر المضيئة على Kick.
  - قسم قنوات ومنصات التواصل (Kick, TikTok, Discord, WhatsApp).
  - قسم دعم VIP مخصص لمنصة **TikAlert**.
  - نبذة تعريفية منسقة مع بطاقات تصنيفات الألعاب.
  - قسم مجتمع المتابعين (سيرفر الديسكورد وقناة الواتساب).
  - فوتر احترافي مع حقوق سنة 2026 وروابط سريعة.

## 🚀 كيفية الرفع على GitHub Pages (خطوة بخطوة):
1. افتح حسابك على [GitHub](https://github.com) وأنشئ مستودعاً جديداً (New Repository) مثلاً باسم `keromega-website`.
2. ارفع جميع الملفات والمجلدات الموجودة في هذا المجلد إلى المستودع.
3. توجه إلى إعدادات المستودع **Settings** -> ثم اختر **Pages** من القائمة الجانبية.
4. تحت قسم **Branch** اختر `main` واضغط **Save**.
5. خلال دقيقة سيظهر لك رابط الموقع المباشر (مثل `https://username.github.io/keromega-website/`).
